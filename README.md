# Калькулятор на языке Go

Учебный проект CLI-калькулятора на Go 

---

## Разработка

Основные команды для работы с проектом:

### Сборка бинарника
```bash
make build
```

### Запуск калькулятора без интерфейса
```bash
make run
# Запуск с заданной точностью (например, 2 знака):
make run P=2
```

### Запуск калькулятора с интерфейсом в терминале
```bash
make ui
# Запуск с заданной точностью (например, 2 знака):
make ui P=2
```

### Запуск тестов
```bash
make test
```

### Проверка линтером
```bash
make lint
```

### Очистка артефактов сборки
```bash
make clean
```

---

## Как пользоваться

### 1. Быстрое вычисление выражения
```bash
./bin/calc "2 + 2 * 2"
# 6

# или через make:
make run ARGS='"2 + 2 * 2"'
```

### 2. Консольный режим (REPL)
```text
$ make run
> 2+2
4
> (10 - 2) * 3
24
> 2 ^ 10
1024
> q
```

### 3. Калькулятор с графическим интерфейсом в терминале
```bash
make ui
# или прямо внутри консольного режима наберите: ui
```
